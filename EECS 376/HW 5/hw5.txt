           6. Decidability.
              Recall that to prove that a problem is decidable, it suffices to provide pseudocode, and prove its
              correctness. It is not necessary to explicitly describe a Turing Machine that solves the problem,
              since any problem solvable by pseudocode can be solved by a Turing Machine, and vice versa.
(5 pts)       (a) Prove any finite language L = {ℓ1 , . . . , ℓn } is decidable.

                     Solution: Define the following decider, where equality means equality of the entire
                     input string.

                      1: for i ← 1 to n do
                      2:    if w = ℓi then
                      3:        return accept
                      4: return reject
                                                     Algorithm 1: FiniteLanguageDecider(w)

                    The algorithm halts because the list has finitely many entries and each string comparison
                    examines only finitely many symbols. If w ∈ L, then w = ℓi for some i, so the algorithm
                    accepts. Conversely, if it accepts, it found an index i with w = ℓi , which implies w ∈ L.
                    Thus the algorithm decides L.

                  Pac-Man will end up back at home (at the origin) after completing the commands.

                     Solution: Let

                                  H = {s ∈ {L, R, U, D}∗ : #L (s) = #R (s) and #U (s) = #D (s)}.

                     Suppose, for contradiction, that a DFA recognizes H. Regular languages are closed
                     under intersection, so intersecting H with the regular language R∗ L∗ would produce a
                     regular language. But
                                                   H ∩ R∗ L∗ = {Rn Ln : n ≥ 0}.
                    The latter language is not regular. Indeed, if its pumping length were p, then the string
                    Rp Lp would have a decomposition xyz with |xy| ≤ p and |y| > 0. Thus y = Rt for some
                    t > 0. Pumping y out gives Rp−t Lp , which is not in the language, contradicting the
                    pumping lemma. Hence H is not regular, and no DFA can decide the homecoming
                    problem.
